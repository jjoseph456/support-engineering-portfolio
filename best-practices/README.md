# Technical Support Best Practices

Public, vendor-documented guidance for operating and supporting GitHub-based
developer platforms.

These articles are original portfolio content. They are based only on public
documentation and synthetic examples. They do not contain customer information,
internal support procedures, private issue references, or confidential product
details.

## How to Use This Collection

Each article separates preventive controls from incident diagnostics:

- **Preventive controls** reduce the likelihood or impact of a failure.
- **Operational signals** show whether the system behaves as expected.
- **Diagnostic evidence** helps isolate the failure layer.
- **Recovery verification** proves service is restored.

The guidance is intentionally version-aware. Always select the documentation
for the exact GitHub Enterprise Server release and verify current GitHub.com
behavior before making a production change.
